
# HTTPS SSL

This project focuses on securing website traffic using HTTPS and SSL/TLS.

## Tasks

- **Task 0:** Configure DNS records and create a Bash script to retrieve subdomain information.
- **Task 1:** Configure HAProxy SSL termination using Certbot.
- **Task 2:** Redirect HTTP traffic to HTTPS.

## Technologies

- Ubuntu
- Bash
- DNS
- HAProxy
- Certbot
- SSL/TLS
